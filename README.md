## 🎯 What Is FTWEBRC?

</div>

<table align="center">
<tr>
<td width="50%" valign="top">

### 💀 The Problem

- ❌ Python venv everywhere
- ❌ Runtime dependencies
- ❌ Slow startup
- ❌ Messy output
- ❌ Not portable

</td>
<td width="50%" valign="top">

### ⚡ The Solution

- ✅ **Single C binary**
- ✅ **No runtime deps**
- ✅ **Fast native execution**
- ✅ **Clean aggregated output**
- ✅ **Just compile & run**

</td>
</tr>
</table>

<div align="center">

**FTWEBRC** is a **lightweight C binary** for web reconnaissance. It orchestrates **subdomain enumeration tools** into one fast, native binary — no Python, no venv, just compile and run.

<br/>

> *"No venv. No pip. No bullshit. Just a C binary that does web recon."*

</div>

## 🏗️ Architecture

</div>

<table align="center">
<tr>
<td width="100%">

| 🧩 Component | 📋 Purpose |
|---|---|
| `ftwebrc` | 🎯 Compiled C binary |
| `src/main.c` | 🧠 Main source |
| `config/tools.txt` | 🛠️ Tool registry |
| `Makefile` | 🔧 Build script |
| `results/TARGET_TIMESTAMP/raw/` | 📁 Per-tool output |

## 🛠️ Troubleshooting

</div>

<table align="center">
<tr>
<td width="50%">

| ❌ Issue | ✅ Fix |
|---|---|
| `ftwebrc: command not found` | `cd ~/PROJECT/FTWEBRC && make` |
| Tool missing | `which subfinder` — install via `go install` |

</td>
<td width="50%">

| ❌ Issue | ✅ Fix |
|---|---|
| Empty results | Check `results/*/raw/` for per-tool errors |
| Permission denied | `chmod +x ftwebrc` |
